# Numbers API Web Application

A simple web application that displays interesting facts about numbers using the Numbers API. Built with vanilla JavaScript and Tailwind CSS.

## Features

- Get interesting facts about specific numbers
- Discover random number facts
- Learn historical events for any day of the year
- Clean and responsive UI with dark theme
- Background starfield animation

## Live Demo

Visit the live demo at: https://ivsevostianov.github.io/numbers/

## Technologies Used

- Vanilla JavaScript
- Tailwind CSS
- Numbers API
- HTML5

## Getting Started

### Prerequisites

- Node.js (latest version)
- npm (comes with Node.js)

### Installation

1. Clone the repository
```bash
git clone https://github.com/ivsevostianov/numbers.git
cd numbers
```

2. Install dependencies
```bash
npm install
```

3. Build the CSS
```bash
npm run build
```

4. For development with live CSS updates
```bash
npm run watch
```

## API Reference

This project uses the Numbers API (http://numbersapi.com/). The API provides facts about:
- Numbers (trivia, math, etc.)
- Dates (historical events)
- Years (historical events)
